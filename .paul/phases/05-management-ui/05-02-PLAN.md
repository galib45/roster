<design>
## App State (single owner: `RosterApp`)

Keep `Page` a `Copy` section enum — do **not** move IDs into it. Context lives beside it.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Page { Organizations, Rosters, Employees, Shifts, RosterPlan, Export }

pub struct RosterApp {
    page: Page,
    project: ProjectFile,
    project_path: String,
    current_org_id: Option<String>,

    status: SharedString,
    org_name_input: Entity<InputState>,
    project_path_input: Entity<InputState>,

    // Organization edit dialog
    show_org_dialog: bool,
    editing_org_id: Option<String>,
    org_edit_input: Entity<InputState>,

    // Positions
    position_name_input: Entity<InputState>,

    // Roster add dialog
    show_roster_dialog: bool,
    roster_add_input: Entity<InputState>,

    _subscriptions: Vec<Subscription>,
}
```

Helper methods:
- `selected_org(&self) -> Option<&Organization>` / `selected_org_mut(&mut self)`
- `save_project(&mut self)` — calls `store::save_project` with `project_path()`, sets `status`
- `select_org(&mut self, org_id: String)` — sets `current_org_id`, clears stale dialogs
- `render_pending(&self, message: &str) -> AnyElement` — used by Employees/Shifts in this plan
- On `load_project`, keep `current_org_id` only if the id still exists; otherwise pick the first organization or `None`

## Layout

- Sidebar stays the six Phase 1 sections (Organizations, Rosters, Employees, Shifts, Roster Plan, Export).
- Rosters, Employees, and Shifts read `current_org_id`. When it is `None`, show: “Select an organization on the Organizations page.”
- Organizations page shows the add form, all organizations (Select / Edit), the selected organization's Positions section, and the project Save/Open row.

## Validation and feedback

- Trim every text value before calling a domain method.
- Empty name → visible `status` message; no mutation.
- Domain errors (`DomainError`) → `status` message; no mutation.
- Successful mutation → `save_project()` and a confirmation `status`.
- Dialog Cancel closes and discards; nothing is mutated until Save.
</design>
